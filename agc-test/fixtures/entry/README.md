# Entry-scenario fixtures

## `entry_template.core`

**Binary template core dump** consumed by the MS-E7d live yaAGC tests
(`agc-test/tests/entry_e2e_vagc.rs`). Captured from a fresh yaAGC cold
boot and used as the resume-from base before the test patches it with
the scenario-specific initial conditions (`agc_test::entry_state`).

**Not committed under version control** — the file is large, fully
deterministic given the assembled Comanche055 rope, and only useful
when a developer has VirtualAGC built locally. Regenerate it with:

```sh
# One-time bootstrap (assembles MAIN.agc.bin etc).
bash agc-test/scripts/assemble_comanche055.sh

# Capture the template.
cargo run --features vagc-capture --bin capture_entry_template
```

When the file is missing, the MS-E7d live tests print a skip notice
and return successfully. CI does not require it.

## `channel_traces/*.json`

Channel-write traces captured by `ChannelTraceRecorder` during MS-E7c
and MS-E7d test runs. The schema is the `ChannelTrace` struct in
`agc-test/src/vagc_trace.rs`. Two sub-categories:

- **`entry_startup_smoke.json`** — hand-built MS-E7c smoke fixture
  exercising the comparator's self-match path.
- **`entry_direct_leo.json`, `entry_lunar_return.json`** — MS-E7d live
  captures (regenerated by running `VAGC_CAPTURE=1 cargo test -p
  agc-test --test entry_e2e_vagc`). Their per-scenario summaries
  live alongside as `*_summary.json`.

## `huntest_*.{toml,json}`

MS-E3b HUNTEST capture inputs / outputs. See
`agc-test/src/bin/capture_huntest.rs`.
